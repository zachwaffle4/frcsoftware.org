---
title: Buenas Prácticas
description: Un resumen de las buenas prácticas para el código de robots de FRC
---

En esta guía documentamos las buenas prácticas de herramientas y los estándares de programación para FRC.

Algunas razones para seguir estas buenas prácticas:

- Ayudan a mantener el orden, lo que facilita gestionar los cambios
- Hacen que el código sea legible y fácil de mantener

¿Por qué estandarizar el código?

- Facilita que todo el mundo tenga éxito
- Fomenta las buenas prácticas
- Reduce el tiempo de depuración
